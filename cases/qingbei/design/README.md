## 入口 A 及其它边界

- A = 基流 200 + 0.413 × Q新盖房(t − 80 h)：沿用 23·7 率定的传递关系，外推到其它量级属于假设
- B 独流减河进洪闸：自由出流，C_d 0.3275，堰顶 1.03 m

- 不考虑降雨；初始水深 0；糙率 n 0.035；时长 288 h；time_origin 2000-01-01 为名义时间

## 已知限制

- 模型范围只有清北，没有清南和文安洼。东淀设计滞洪水位 8.0 m（第六埠），设计滞洪量 12.68–12.88 亿m³。
  按调度规则，第六埠水位达到 7.0 m 后要通过清南分洪闸分洪。50/100 年一遇时清北的水位会因此偏高。
- 安全区按不漫顶处理；DEM 高程基准按 1985 国家高程处理（误差约 ±0.8 m）。
- 驱动程序 v1 没有 DESIGN 状态，入流状态字段填的是 RECONSTRUCTED_NOT_MEASURED，配置描述中写明了来源。
