# R2A offline result package implementation

`hydrodynamics.rehearsal_package` implements the local-only `rehearsal-result-package-v1` adapter for the pinned `r2a_flat_bed_closed_v1` synthetic fixture. It reads an existing triangular closed-wall, `sources=none` result and revalidates the current run config, P3-A package, P2 mesh, topology and terrain through the existing P4-1 result reader. It does not call the solver or alter source files.

The export request names the run config, a separate local dispatch assignment, an R1 execution envelope, output directory, scope, metric policy and requested products. `make-local-envelope` computes the local source graph input digest and writes the matching R1-shaped envelope without authenticating a platform. Identity comparison reuses `validate_execution_identity` with expected values from the distinct assignment file. Package identity explicitly labels authentication `NOT_ASSESSED` and native identity as outer-context-only.

The package contains the raw NetCDF, original request/envelope/assignment bytes, per-frame maximum depth and area-integrated volume, static reference volume, global maximum depth/time/face and maximum volume/time, exact selectors with data bindings, product coverage, quality checks and a relative-key file manifest. G1 evidence is optional for export but required for a complete offline review. Existing G1 bytes are preserved and checked by the existing pair validator, original result path, native format/full time axis and local script binding; the validated native file provides the case ID when legacy G1 context does not repeat it. No path is rewritten. Incomplete packages are retained for review; CLI exit code 3 means valid but incomplete when `--require-complete` is set. Invalid input or corruption returns code 2.

The final fresh validation runs inside the same export transaction as the stage validation and directory rename. If it raises after publication, rollback removes the success manifest first and removes only files/directories whose filesystem identities still match the tree created in the private staging directory. Before unlinking a file, it checks every parent directory identity in the path; replacing `native/` therefore preserves any concurrent hardlink placed beneath the replacement directory. It does not recursively delete the published directory. On Windows, output paths are checked for `FILE_ATTRIBUTE_REPARSE_POINT` components (including junctions) and their resolved path must remain a new child beneath the request directory. This uses `stat_result.st_file_attributes` and does not depend on Python 3.12's `Path.is_junction`.

If another writer modifies or replaces the transaction manifest, rollback writes its exact current bytes to a uniquely named `manifest.recovered.<id>.json` file using exclusive creation, then retires the success marker when the parent chain remains owned. If the root or a parent directory was replaced, rollback leaves that content untouched and reports its path; if byte recovery fails, it leaves the manifest in place and reports the recovery failure. Concurrent extra files and replaced/modified data files are preserved. A failed export may leave foreign or recovery files in the output directory, but rollback does not leave the original successful manifest when it can safely identify it. Valid incomplete packages are not rolled back.

Validation independently rebuilds expected package contents from the original local source graph and actual NetCDF arrays. It rejects missing source inputs, symlinks, unknown/extra files, unsafe or duplicate keys, hash/size mismatch, changed identities, changed selectors, and derived metrics that differ from source arrays. `validation_basis=LOCAL_SOURCE_GRAPH_V1` means the package is not portable without its original input graph.

The metric policy `r2a-static-flat-bed-v1` is limited to the synthetic 0.2 m still-water reference. Areas come from the actual P2 mesh. Every saved face depth and each frame's integrated volume must be within an absolute `1e-12` m or m³ of the reference. Maximum-depth ties select the earliest time, then the lowest face ID. The adapter does not calculate or approve real-world risk, exposure, evacuation, open-boundary, rainfall, Manning, or 3-D products. All packages stay in offline review staging with publication and engineering validation false.

The runnable inputs and local G1 helper are in [`examples/rehearsal_package/`](../examples/rehearsal_package/README.md).
