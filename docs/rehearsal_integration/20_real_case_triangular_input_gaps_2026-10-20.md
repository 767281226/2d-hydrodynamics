# 真实工程转入原生三角链路的输入缺项

本记录仅梳理已有配置和已验收能力，不启动工程、不打开真实DEM/NPZ/CSV业务记录、不恢复地图删除或修改原数据。依据case_001的config.yaml/workflow.yaml、原生closed_wall模板、记录11/17/18/19；旧配置中的历史“尚未实现”注释不能覆盖后来已验收的P4能力。

## 当前明确事实

case_001仍是structured/hourly回放入口，配置EPSG:4548、50m网格、2023-08-01T02:00:00+08:00开始、288小时。workflow显式启用map/securityArea安全约束；该入口会在模型执行前明确拒绝，不能把它当作原生三角工程入口。旧100001仍是历史结构化产物。

已具备P2/P3准备、封闭壁面none/Manning/rain/combined实验运行、原生结果及v1/v2三角SHP。开放边界准备合同不等于开放边界数值执行，当前支持路径保持closed_wall。不以补默认值方式假设工程入出流为零或套用全域填洼。

## 输入清单与缺口

| 环节 | 已知配置/已有能力 | 工程启动前仍须确认 |
|---|---|---|
| 原域D | 旧配置仅给structured外框及NPZ路径 | 可信蓄滞洪区实际面域、孔洞/分区、来源版本和CRS；不能以安全区bbox或旧矩形外框冒充真实D |
| 安全区S | 原始SHP路径与4490声明明确；17已有只读几何兼容证据 | 与工程原域D的合法差集及可表达性；以D减S准备新网格，旧准备件不得复用 |
| DEM | 配置指向data/dem/DEMn_1m.tif，NoData=-32767，目标1985国家高程基准 | 原始水平/垂直单位、源高程基准证据、掩膜和覆盖策略；目标声明不能当作源基准证明。本轮未打开该文件 |
| 网格尺度与资源 | 现有导入/Gmsh及质量/几何容差/face上限合同 | 工程网格目标尺度、局部加密、约束线、质量门槛、面/像素/交叠预算；未按旧dx/dy机械拆方格，也未冻结新的工程数值值 |
| 地形映射 | 独立面积映射与缺测拒绝，GeoTIFF Reader只读原值/掩膜 | 原生active面上的可靠高程覆盖及datum；不补NoData、重投影或静默改DEM |
| 初值 | 旧配置constant_depth=0，原生P3支持depth/level字段 | 实际事件起始水量/水位依据；若采用零初水应有工程来源确认。按新active面积计算，不迁移旧整域体积后再平均 |
| 糙率 | 旧n=0.035标为legacy单位1，现有source prep要求显式SI解释 | 工程分区/来源、s/m^(1/3)物理解读及rationale；不能仅因数值相同宣称工程参数已证实 |
| 降雨 | 旧配置声明273mm按288h均摊，workflow说明为重建过程而非站点实测 | 雨量来源/时段/单位、保存时刻与分段对齐、active接受与排除区未模拟部分；不能自动将排除雨汇入外域 |
| 入出流边界 | 旧配置引用inflow/outflow CSV及west/east结构化位置 | 实际物理边界几何/分组、流量或水位方向/单位/datum/时间来源；closed_wall不能承载真实入出流。开放边界执行需后续明确设计与批准 |
| 旧回放参数 | eta_crest、water_surface_slope、max_spread、area_schedule存在 | 这些是旧回放设置，不能直接替代三角SWE的边界/地形/源项或校准证据 |
| 堤线/闸控 | 几何约束、准备绑定及调度来源记录可追溯 | 几何标签不等于堤高、越流/溃口或真实闸门水力。不得推断实际闸控已执行；新增物理需单独决定 |
| 校验与发布 | 小型合成守恒、native/source/SHP证据链已通过 | 独立观测、工程范围与误差目标、数值稳定/质量预算、正式工程验收依据。当前experimental/can_publish=false不变 |
| 展示/统计 | 原生SHP可由GIS读取；部分旧web编码器仅structured | 原生三角web编码、人口/损失/风险等未实现项明确UNSUPPORTED；排除安全区不能解释为零风险 |

当前工作树workflow还包含其他未提交DB/社会经济路径，它们不构成本批工程数据授权或已验收输入，本次发布不夹带这些WIP。
