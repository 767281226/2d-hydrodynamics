## 不变边界

采用D减去安全区并集S的计算域排除；新的排除边界为已批准closed_wall。无堤高/越流/实际闸控、新干湿规则或源项物理；不改原始DEM/地图/100001历史输出。只使用小型合成数值验证；真实安全区只做本次已授权几何/CRS只读兼容核查。不得读真实大DEM或社会经济数据，不跑工程大算例，不连接DB/HTTP/Java/Vue。

## S0 输入和准备合同

1. 独立严格、版本化安全区合同及读取/几何规范化模块。每个参数明确类型、单位、默认/必填、合法范围和错误信息，CRS必须真实声明；源几何只读、未知CRS/非法面/空几何/非有限/自交等拒绝，禁止buffer(0)等静默修复。支持有效Polygon/MultiPolygon、多个记录的并集；交叠部分只排除一次，原源ID/摘要与规范化并集均可追溯。只投影矢量到实际网格米制CRS，不改DEM。
2. 配置显式声明安全区enabled/source及constraint=excluded_closed_wall，默认通用合成场景可为未配置；examples/case_001等对应真实项目默认入口必须引用map/securityArea/dd_securityArea_shape.shp并启用，防止用户继续无保护运行。打包合成profile继续显式SYNTHETIC_ONLY，不假称使用该真实约束。不能依赖任意cwd猜测或自动扫描本地文件来隐式改变计算。
3. 明确原始计算域D及其来源，不以安全区自己的bbox充当D。对导入网格需有足以核对D\S覆盖的受信域几何/边界契约；不能只看face中心。记录原域面积、安全区并集面积、域内排除面积、域外安全区面积、实际面总面积及覆盖残差。域外安全区可明确零影响并保留来源；边界接触及正面积部分相交需严格几何处理。
4. 生成网格时先作几何差集并用已有Gmsh约束表达实际域；导入网格必须逐面验证与S无正面积交叠、并集覆盖D\S、排除边组为真实外边，不把安全区标签当作阻水。若某自动生成情况（边界切割、差集多分量、带孔安全区内保留的水域岛等）当前适配器不能正确表达，应在预检中给具体UNSUPPORTED原因，不能删掉区外面积、把安全区孔洞填为干域或悄悄降级。有效多面及并集须支持；带孔几何的保留含义须至少在导入贴合网格支持或明确拒绝。
5. mesh_id/topology、source geometry/CRS/规范化几何摘要及安全区版本进入准备/执行身份。安全区或网格改变后旧P3初值/糙率/source准备、旧执行信封、旧结果/SHP验证不能被复用；复用现有摘要绑定并增加必需的排除证据，validator重读实际几何/面集合，不能信任自报security_applied=true。

## S1 执行与水量

6. 三角none/Manning/rainfall受支持入口在数值推进前执行共同安全区/网格一致性守卫，使用现有边通量和壁面；不修改一阶HLL/静水重构/SSPRK2等公式。无法表达排除的旧structured/Hourly入口在enabled=true时明确拒绝且无伪成功产物；无安全区时兼容计算保留。不要用全域fill_volume跨安全岛重新分配水量来冒充封闭壁面物理。
7. 初始水深constant的定义域是新的active计算域，预算初始体积由实际面面积积分。显式落在安全区内的正初始水/源点、旧整域已分配水量及来自不匹配网格的逐面初值不能静默裁掉，明确拒绝并要求重新准备。不可把原域初始体积拿到新域再平均分配。
8. 已批准均匀降雨只按active实际面积积分，区内不产生状态或源项。报告active域接受降雨、安全区域外未模拟降雨份额与二者的关系；此后者不是已接受预算的损失，也不自动汇流到外域。若输入声称全原域指定总水量均需进入计算、却未给安全区降雨径流去向，则拒绝该输入语义；新汇流/管网等物理另行决定。边界流量/雨量/source绑定到排除区也必须拒绝或按既有明确定义的active域来源处理，禁止静默丢水。
9. 正常结果逐时/逐帧仅包含真实active面；安全区为EXCLUDED/非计算域，不能先算出正水深再清零。受支持运行记录实际区外水量预算、壁面零质量通量、源项/修正及排除几何证据。边界只共享零面积线/点时不能把它算作湿安全区自由度；正面积越界不得隐藏。
