推荐：同一场景版本/运行/结果集驱动五页；数据库保存可查询业务数据和结果索引，大网格文件由受控存储承载。现有资料、规则、安置点和路线基础数据引用复用，不重复建设。缺失的模型/风险/避险能力显式缺项，不填演示假数。

已核对本地HTTP页面引用的JS与用户提供的演示包完全一致；没有可用网页浏览器连接，未进行DOM交互验证。前端业务仓库已有 `/flood/rehearsal` 页面，本方案不是另做演示站。

当前模型仍限既定合成验收范围，开放边界/真实风险与自动撤离能力不因页面对接而自动获得工程认可。此前取消的聊天定时任务保持删除。
